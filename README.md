# 📊 Оценщик недвижимости в городе Астана

## Описание проекта

Данный проект представляет собой веб-приложение на Streamlit для прогнозирования стоимости недвижимости на основе машинного обучения.

Модель обучена на исторических данных и учитывает характеристики объектов недвижимости, включая:
- площадь
- количество комнат
- район / жилой комплекс
- дополнительные признаки объекта

## 🚀 Функционал

- Ввод параметров недвижимости через интерфейс Streamlit
- Автоматическая обработка признаков (one-hot encoding)
- Предсказание стоимости в реальном времени
- Интерактивный веб-интерфейс

## 🧠 Используемые технологии

- Python
- Pandas, NumPy
- Scikit-learn
- RandomForestRegressor / XGBoost
- Streamlit
- Joblib

## 📦 Архитектура проекта

1. Обработка данных (EDA)
2. Преобразование категориальных признаков
3. Обучение модели
4. Сохранение модели (`model.joblib`)
5. Сохранение списка признаков (`columns.joblib`)
6. Streamlit приложение для предсказаний
